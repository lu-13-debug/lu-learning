# 数据分析与软件测试项目

四个独立仓库分别提供完整代码、运行入口、依赖说明和结果报告。

| 项目 | 技术与功能 | 独立仓库 |
|---|---|---|
| 电商用户行为与交易分析 | Python、Pandas、SQL；清洗、漏斗、留存和 RFM 分群 | [ecommerce-user-analytics](https://github.com/lu-13-debug/ecommerce-user-analytics) |
| 零售门店销售日报与异常分析 | Python、SQLite；经营日报、门店排名与异常基线 | [retail-sales-analysis](https://github.com/lu-13-debug/retail-sales-analysis) |
| 电商购物流程 Web 自动化测试 | Playwright、JavaScript、Python；页面回归与订单 SQL 核验 | [ecommerce-web-automation](https://github.com/lu-13-debug/ecommerce-web-automation) |
| 客户工单管理接口测试 | Python、HTTP、SQLite；状态流转、账号隔离与落库检查 | [customer-ticket-api-tests](https://github.com/lu-13-debug/customer-ticket-api-tests) |

每个仓库的 README 包含功能、技术栈、安装运行、数据规则和输出结果。下载对应仓库后即可独立运行；HTML 报告以离线文件形式提供，JSON 与 CSV 可以直接在 GitHub 查看。
